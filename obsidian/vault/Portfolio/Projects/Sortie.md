Sortie is a file organizer styled as a <strong>Google Drive × macOS Finder</strong> hybrid. Sorted files <strong>fly into their folders</strong>, and deleted files get sucked up by a <strong>vacuum cleaner</strong> into a recoverable Vacuum bag. Finder-style sidebar with Favorites, Folders and Tags, Drive-style filter chips and selection bar, icon and striped list views, back/forward history and a path bar. An <strong>AI assistant</strong> (offline rule-based helper, or OpenAI, Anthropic, Gemini, OpenRouter, Groq, Ollama and LM Studio) turns plain requests such as “vacuum duplicates” into a plan you Run or Cancel; everything is undoable. Works on real folders in Chrome and Edge via the File System Access API, with demo and preview modes that never touch the disk. Installable PWA, light and dark themes, no build step.
