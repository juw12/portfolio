# Loka

Offline Windows translator for English, Chinese (Simplified/Traditional) and Bahasa Indonesia, powered by a local Ollama model with tone, glossary and review checks.

- **Windows app** — https://juw12.github.io/projects/loka-translate/
- **Source** — https://github.com/juw12/projects/tree/main/apps/loka-translate

Native desktop application. No browser/mobile translator is claimed.
