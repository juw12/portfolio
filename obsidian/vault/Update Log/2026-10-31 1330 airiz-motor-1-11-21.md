# Update - airiz-motor 1.11.21 (Go home keyboard + camera-based night mode)

- What: AIRIZ Console 1.11.21 closes two Camera-tab rough edges. Pressing **Home** on the keyboard now sends the camera home on the Camera tab (outside fields, dialogs and the side nav, no modifiers, no key-repeat) — same `goHome()` path as the button, routed through `askHost('go-home')` so a remote controller still asks the cable console. The `Go home` button is now `try`/`catch`-wrapped so a thrown error from `moveTo`/`readSwitch`/`findRisingHome` becomes a visible status line, not a silent no-op. Auto night vision now uses **both** the on-board light sensor and the camera picture: camera mean luminance is sampled on the main thread every ~700 ms (the camera path cannot run inside the `analyse()` worker, which has no DOM / `api.sendCommand`), a 6-sample rolling buffer smooths it, and a new `combinedNightDecision()` in `ptz-core` says night when either source says dark and only switches back to day when both say bright — so a covered ALS or a covered lens no longer freezes the wrong mode. New `store.night.camera` flag (default on) plus `cameraDarkBelow` (22) / `cameraBrightAbove` (60) thresholds in 0..255 luminance units, tunable in the UI. Status line now shows both readings: `ALS 12 · cam 18 · Night (IR)`. ALS-only behaviour is one click away.
