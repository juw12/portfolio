# Update - kinibuka

- When: 2026-11-02 09:23
- What: New app. KiniBuka ("now open") helps people find small Indonesian UMKM stalls that are open right now: a live feed of openings, closings, new branches, promos and bazaars, an Explore map with search, follow alerts, and order-ahead with one-tap WhatsApp handoff. Sellers toggle open/closed per branch and manage menu, promos, bazaars and incoming orders. ID / EN / 中文 interface; plain Python server on SQLite.
- App: no hosted demo (needs the Python server); run `apps/kinibuka/run.bat` or `python server.py`
- Source: https://github.com/juw12/projects/tree/main/apps/kinibuka
- Repos: juw12/projects (`apps/kinibuka/`, `scripts/apps.json`, `scripts/publish_portfolio.py` url_label option), juw12/portfolio (card, notes), juw12/juw12 (profile, Building section), juw12/obsidian (notes)
- Checks: local server run; Latest, Explore and stall screens reviewed in English; i18n keys present in all three languages; portfolio card passes the house-style check.
- Status: working prototype. Not yet verified: automatic WhatsApp sending through Fonnte / Meta Cloud API (no credentials configured), phone login has no OTP, not hosted.
