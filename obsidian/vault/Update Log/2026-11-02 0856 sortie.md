# Update - sortie

- When: 2026-11-02 08:56
- What: New app. Sortie is a playful file organizer in a Google Drive x macOS Finder style: sorted files fly into their folders, a vacuum cleaner sucks deleted files into a recoverable Vacuum bag, and an AI assistant (offline helper or your own OpenAI / Anthropic / Gemini / OpenRouter / Groq / Ollama / LM Studio) turns plain requests into a plan you Run or Cancel. Everything is undoable.
