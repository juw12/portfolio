# Update - airiz-motor 1.11.20 (wobble test fixes)

- When: 2026-10-31 12:00
- What: AIRIZ Console 1.11.20 fixes the wobble test. Pressing Start again right after a test now starts with the rise (the head is already down) instead of driving down into the bottom end stop again, also when the bottom switch reports the head is down; a manual rising jog in between makes it lower first again. The "camera picture hardly updates" check counts one second from the first camera frame, and the console stays at full speed while the test runs even behind other windows; a camera that is really slow in dim light gets a clear message. Height reference and Calibration are hidden and Motor speed moved to the Position group. The console window always shows on start (before, the app could keep running with a hidden window).
- App: https://juw12.github.io/projects/airiz-motor/
- Download: https://github.com/juw12/projects/releases/tag/airiz-desktop-v1.11.20
- Checks: 123 desktop unit tests and 20 console UI tests pass; packaged-app smoke test passed with no JavaScript errors; the real wobble-test code was run against a simulated AIRIZ and camera (repeat test, manual jog in between, 5 fps camera, slow first frame, bottom switch pressed).
- Limits: not yet run on a real AIRIZ; the update feed is refreshed by the release workflow.
