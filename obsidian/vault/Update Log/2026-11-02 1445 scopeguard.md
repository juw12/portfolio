# Update - scopeguard

- When: 2026-11-02 14:45
- What: New app. ScopeGuard keeps a business AI assistant on its mission and stops users turning it into a free general-purpose chatbot. Every message is allowed, answered briefly and steered back (related questions), redirected without calling the LLM (off-topic), throttled after a daily allowance, or blocked (jailbreaks / prompt injection). The app runs the guard entirely in the browser: chat as different users, simulate demo traffic, and a dashboard with off-mission share, estimated LLM cost avoided, unmet-demand themes, flagged users and a review queue that teaches the classifier instantly. Policy editor with import/export and three templates (CAD copilot, bank support, online store), an Accuracy page with held-out test sets or your own cases, day/night theme, installable PWA. A self-hosted standard-library Python server (check API, OpenAI-compatible proxy, admin dashboard, SQLite log, optional LLM judge) uses the same engine and policy JSON.
- App: https://juw12.github.io/projects/scopeguard/ (local mode; data stays in the browser)
- Source: https://github.com/juw12/projects/tree/main/apps/scopeguard
- Repos: juw12/projects (`apps/scopeguard/`, catalog entry), juw12/portfolio (card, note), juw12/juw12 (profile, Building section), juw12/obsidian (notes)
- Checks: CI suite `tests/test_scopeguard_web.py` passes (deploy safety, XSS guard, templates, 19-test server suite); browser suite 11/11 in headless Edge - the JS engine matches the Python engine on 202 messages x 3 templates and 65 sequential session decisions; `build_site.py` and `check_site.py` pass with no ScopeGuard warnings.
- Accuracy (CAD policy, local classifier, no LLM judge): served-vs-stopped 85% on a never-tuned final set (1/11 real users wrongly redirected, 2/9 off-topic let through with a steer-back hint), 89% on a blind set; the 100% on the tuning set is optimistic and not claimed.
- Status: working prototype. Keyword/TF-IDF matching does not understand meaning (enable the server's LLM judge for production); no streaming in the proxy; sessions in memory; not load-tested and not audited against any compliance standard.
