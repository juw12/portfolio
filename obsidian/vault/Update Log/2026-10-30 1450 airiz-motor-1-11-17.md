# Update - airiz-motor 1.11.17 (real device facts)

- When: 2026-10-30 14:50
- What: AIRIZ Console 1.11.17 replaces dashboard decoration with what the AIRIZ really reports. The strip under the buttons shows the firmware the device answers to `diag ver sw` next to the firmware the command list was written for; Bluetooth test reads the result (OK + controller address or error code); the header shows the link and the last reply, "Connected for" replaces the session clock, and the sidebar bars are real bytes per second. With the camera preview on, every jog checks the picture before and after and says whether the camera really moved. Calibration can measure aim and timing automatically from the camera picture. The siren is a generated rising/falling wail (AIRIZ test sound still selectable). Listen volume is renamed PC playback volume. New read-only Hardware check: firmware, motor driver files, accelerometer, buttons, light sensor, kernel, storage and the camera's zoom controls, saved as a report.
- App: https://juw12.github.io/projects/airiz-motor/
- Download: https://github.com/juw12/projects/releases/tag/airiz-desktop-v1.11.17
- Checks: 112 unit tests (new image-shift, motion-stop and siren-tone tests); demo-mode browser test 17/17 with a fake webcam (`desktop/tests/device-facts-e2e.cjs`); packaged-app smoke test passed with no JavaScript errors; live update feed serves 1.11.17.
- Limits: tested with the demo device and a fake webcam only; real AIRIZ answers (accelerometer format, motor status file, move-check sensitivity, siren over the voice link) still need a bench run of Hardware check.
