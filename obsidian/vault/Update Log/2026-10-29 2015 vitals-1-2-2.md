# Update - vitals 1.2.2 (instant process list on work PCs)

- When: 2026-10-29 20:15
- What: On managed Windows PCs the "what's running" list came back empty. Without psutil the agent used `tasklist /v`, which looks up every process owner on the domain and every window title and took about 40 s, longer than the request waits. Vitals now reads processes straight from the Windows API (Toolhelp snapshot plus per-process CPU time, memory and owner): about 0.5 s for 420 processes on the same PC, with memory, owner and CPU % filled in. Plain `tasklist` stays as a fallback. The release page now also explains that the Android and iPhone apps check the phone itself.
- Download: https://github.com/juw12/projects/releases/tag/vitals
- Repos: juw12/projects (`apps/vitals/server/metrics.py`, `apps/vitals/tests/verify_api.py`, `.github/workflows/vitals-apps.yml`; commit 6b01a52), juw12/portfolio (notes), juw12/juw12 (profile line)
- Checks: on the managed PC itself: 424 processes in 0.47 s (was ~40 s), memory and owner present, CPU % on repeat calls; API suite now fails if the process list takes 5 s or more or has no memory figures; every desktop app, the Android emulator check and the iPhone simulator check rebuilt green in CI.
- Limits: processes owned by other accounts or protected system processes show no owner or memory when Vitals isn't running as admin (Windows doesn't allow it).
