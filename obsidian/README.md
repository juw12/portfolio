# Portfolio — Obsidian vault

Project notes for every app and model in the portfolio, as a ready-to-open [Obsidian](https://obsidian.md) vault.

## Download

- **Full bundle:** [`juwen-lie-portfolio-obsidian-vault.zip`](juwen-lie-portfolio-obsidian-vault.zip) — open it on GitHub and press *Download raw file*, unzip, then in Obsidian choose *Open folder as vault* and pick `Juwen Lie Portfolio`.
- **Whole repo:** green *Code* button → *Download ZIP* (vault is in `obsidian/vault/`).
- **Single notes:** browse [`vault/`](vault/) — every note is plain Markdown and reads fine on GitHub.
