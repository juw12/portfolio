Vertex

Vertex is one local, offline, zero-dependency 3D app that unifies a parametric part builder with a universal 3D engineering copilot. Build geometry from parameters/primitives and export real 3D files (STL ascii+binary, OBJ, glTF 2.0, 3MF, DXF); read a host-agnostic ModelReport and get a typed Diagnosis of what is broken (failed fillets, broken references, dangling or circular dependencies, failed mates) with an ordered upstream-first Repair plan and an Assembly plan (base part + insert/mate steps + structural checks); ask questions about the design and get deterministic Answers with evidence (failed features, dependencies, mates, how-to); reverse-engineer a point scan into editable parametric CAD; turn a drawing spec into a model; run batch Automation (export / pattern / drawing sheets); and run deterministic simulations (kinematic assembly motion, mass properties, clearance/interference). A universal adapter layer covers Fusion, SOLIDWORKS, FreeCAD, Blender, Onshape, Rhino, SketchUp, Inventor, AutoCAD, CATIA, Solid Edge, Creo, Maya and open formats STEP/STL/OBJ/glTF/3MF/DXF. The geometry core is a pure function (identical input yields byte-identical output); every action passes a dry-run and review gate; with no CAD host attached it runs in a fully usable simulation mode and never writes to CAD. It complements cloud AI CAD copilots (like Vector) by staying local, open, deterministic, auditable and review-gated.

3D parametric CAD 3D file export design Q&A reverse engineering drawing to CAD automation simulation offline-first deterministic

Marina Bay Sands Miniature

A tabletop miniature of Marina Bay Sands, modelled as parametric CadQuery by an AI agent in SOMA. Three curved glass hotel towers — bowed bay-facing facade, slight taper — stand in a straight row and are joined on top by the boat-shaped SkyPark, whose long cantilever curls upward like a ship's bow past the last tower. About 250 mm tall, Z-up on the z=0 ground plane, and driven entirely by twelve live parameters (tower height, width, depth and gap; facade bow; taper; SkyPark width, thickness, cantilever, tip rise and far-end overhang). Every edit rebuilds deterministically and exports to STEP and glTF.

3D Works

Eiffel Tower

A simplified solid Eiffel Tower modelled at 1:1000 in millimetres, so the 330 mm miniature matches the real tower metre for metre: a 125 m base square, the first floor at 57.6 m, the second at 115.7 m, the third at 276 m and the antenna tip at 330 m. Four lofted legs splay from the base and merge into the tapering shaft, joined by elliptical arch plates; cut-back slabs mark each floor, topped by a lantern and a two-stage spire. Modelled programmatically with open CASCADE (OCP) in Vector and exported as STEP, with a triangulated STL preview. The iron lattice is not modelled — legs, arches, floors and spire are solid, and the whole part is one watertight solid (1,744-triangle preview).

SOMA

SOMA is an open-source desktop CAD app where a coding agent does the CAD — you describe the part, the agent writes it as CadQuery Python, and SOMA rebuilds and shows the result on every change. Measure, mark up the view, tune parameters, step through history, run overhang and wall-thickness checks plus FEM analysis, then export STEP/STL/3MF/DXF with PDF drawings. Bring your own CLI agent (Claude Code, Codex, OpenCode, Gemini CLI). By Kai Jungsthöfel. GPL-3.0. Windows / macOS / Linux.
