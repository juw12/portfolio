Photo2CAD

PRD + six reference photos to a validated STEP (.stp) CAD model via an LLM-written CadQuery program - a deployable service.

Engineering service that turns a product requirements document (PRD) and six reference photographs (front/back/left/right/top/bottom) into a real CAD file. A Pegatron MAAS LLM writes a parametric CadQuery program from the PRD (the photos are visual/dimension reference), a sandboxed child process builds it, and the server re-imports the STEP to validate a single solid with its bounding box and volume - returning a downloadable .stp plus an STL preview. Ships as a deployable web service (Docker + Kubernetes). Output is STEP; Creo .prt is proprietary and not produced (Creo imports STEP).
